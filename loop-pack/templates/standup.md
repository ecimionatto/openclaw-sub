# Standup Log

Append one row per merged task. Format: `| DATE | TASK-ID | PR | verdict | notes |`

To add a row manually: edit this file and append a line like the example below.

| Date | TASK-ID | PR | Verdict | Notes |
|------|---------|----|---------|-------|
| YYYY-MM-DD | TASK-001 | #1 | APPROVE | example row |
